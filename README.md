# Гэрлийн тусгалын виртуал лаборатори

8-р ангийн физикийн интерактив лаборатори. Сурагч хавтгай толин дээрх тусгалын
хуулийг (θᵢ = θᵣ) жинхэнэ лабораторийн дарааллаар туршиж, өөрөө нээнэ:
өрөөг харанхуйлж, цацрагийг толинд тусгаж, замыг нь цаасан дээр тэмдэглээд,
протрактороор өнцгийг хэмжиж, хүснэгт ба графикаар дүгнэнэ.

## Боломжууд

- **Бодит лабораторийн орчин** — модон ширээ, наасан цаас, гэрлийн хайрцаг
  (1 эсвэл 3 ангархай) ба лазер, харанхуй өрөө
- **Жинхэнэ физик** — цацрагийг тусгалын томьёогоор вектороор тооцно:
  r = d − 2(d·n)n. Цацраг толийг алдаж, ар талд нь тусаж ч болно
- **Протрактор** — чирж, эргүүлнэ; O цэг ба толины шугамд наалдана; 2×, 3× томруулна
- **Хэмжилт** — цацрагийг харандаагаар тэмдэглэх; өнцгийг хүснэгтэд автоматаар
  (0.5° хүртэл тоймлон) эсвэл протрактороор уншиж гараар бичих
- **Шинжилгээ** — жинхэнэ утгатай харьцуулсан алдаа, графикийн налалт k;
  «өнцгийг толины гадаргуугаас хэмжсэн» түгээмэл алдааг илрүүлнэ
- **Нэмэлт туршилт** — толийг эргүүлэх (Δ = 2β), барзгар гадаргуу
  (сарнисан тусгал), зэрэгцээ цацрагууд
- **Хэрэглээ** — 8 алхамтай явцын самбар, багшийн туслах горим, гараар удирдах
  (сум — зөөх, Q/E — эргүүлэх), бүрэн монгол интерфэйс

## Технологи

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · SVG.
Физикийн тооцоо гадны сангүй, бүгд браузерт ажиллана.

## Ажиллуулах

```bash
npm install
npm run dev
```

Дараа нь http://localhost:3000 нээнэ.
